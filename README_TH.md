# SoruMate · เวอร์ชันแยกสามภาษา / Render

- **ไทย / 日本語 / English**: สลับภาษาแล้วเปลี่ยนข้อความทั้งหน้า โดยแยก UI ภาษาเดียวในแต่ละครั้ง
- หน้า **สแกนขยะ**: วางปุ่มค้นหาสิ่งที่ AI ตรวจไม่พบ **ท้ายหน้าสแกน**
- หน้า **ค้นหาวิธีทิ้ง**: พิมพ์ชื่อ → เลือกผล → ตอบข้อมูลวัสดุ/สภาพถ้าจำเป็น → ดูผลที่อ้างอิงข้อมูลหลังบ้าน
- หน้า **ขยะ 25 ชนิด**: รายการสั้น กรองตามวัสดุ ไม่ใช้การ์ดยาวหลายภาษา
- หน้า **ประเภทขยะเมือง**: แยกออกเป็นหน้าใหม่ พร้อมลิงก์คู่มือเมือง
- ชุดข้อมูลกฎอยู่ `data/waste_catalog.json` ฝั่ง Backend (ไม่ใส่ใน HTML)
- **สำคัญ** รายการ 25 ชิ้นเป็นแค็ตตาล็อกต้นแบบ ยังไม่เทียบกับ `data.yaml` จากโมเดลล่าสุด
- AI detection: `/predict` และ `/api/predict` ยังไม่พร้อมถ้าไม่ตั้ง ROBOFLOW_API_KEY และ ROBOFLOW_MODEL_ID (ต้องทดสอบกับโมเดลจริง)
- ค้นหานอก 25 ชิ้นจะแสดงคำแนะนำให้ตรวจคู่มือ ไม่สร้างคำตอบขึ้นเอง

## การขึ้น Render โดยไม่สร้างโปรเจกต์ใหม่
1. แตก ZIP
2. อัปโหลด `main.py`, `requirements.txt`, `render.yaml` ไว้ที่ root ของ GitHub repository เดิม
3. อัปโหลด `static/index.html`, `static/sorumate.html`, `static/sorumate-ui.js` ลงในโฟลเดอร์ `static`
4. **ลบ** `static/sorumate-rules.js` เดิมได้ (ไม่ได้เรียกใช้แล้ว)
5. อัปโหลด `data/waste_catalog.json` ไปที่โฟลเดอร์ `data`
6. Commit แล้ว Render > Manual Deploy > Deploy latest commit
7. ทดสอบ `/api/catalog`, หน้า Search และปุ่ม ไทย / JP / EN

ตัวอย่าง UI นี้ใช้ตามดีไซน์ SoruMate เดิม ไม่สร้างเว็บไซต์หน้าตาใหม่
